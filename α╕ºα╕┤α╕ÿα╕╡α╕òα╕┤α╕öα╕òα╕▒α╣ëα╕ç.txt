แอพผัง VPD ห้องปลูก (v1.0) — วิธีติดตั้งบนมือถือแบบใช้งานออฟไลน์
====================================================================

ไฟล์ในชุดนี้
------------
index.html            หน้าแอพ (ผัง VPD + ตัวคำนวณ)
manifest.json         ข้อมูลแอพ (ชื่อ, ไอคอน, สี)
service-worker.js     ทำให้แอพเปิดได้แม้ไม่มีอินเทอร์เน็ต
icons/                ไอคอนแอพ (4 ไฟล์)

สำคัญ: ต้องอัปโหลดทุกไฟล์ และโครงสร้างโฟลเดอร์ต้องเหมือนเดิม (โฟลเดอร์ icons ต้องอยู่ข้าง index.html)
แตกไฟล์ zip ก่อนอัปโหลด


ขั้นที่ 1: นำแอพขึ้นเว็บด้วย GitHub Pages (ฟรี ไม่ต้องเขียนโค้ด)
-----------------------------------------------------------------
ทำบนคอมพิวเตอร์ จะสะดวกที่สุด

1. สมัครบัญชีที่ https://github.com (ถ้ามีแล้วให้ล็อกอิน)
2. กดปุ่ม "+" มุมขวาบน > New repository
     - Repository name: vpd-app
     - เลือก Public (GitHub Pages แบบฟรีต้องเป็น Public)
     - กด Create repository
3. ในหน้า repository ใหม่ กดลิงก์ "uploading an existing file"
4. ลากไฟล์ทั้งหมดจากโฟลเดอร์ที่แตกแล้ว (index.html, manifest.json,
   service-worker.js และโฟลเดอร์ icons) ไปวางในหน้าเว็บ
   รอจนอัปโหลดครบ แล้วกด Commit changes
5. ไปที่แท็บ Settings > เมนูซ้าย Pages
     - Source: Deploy from a branch
     - Branch: main  และโฟลเดอร์ / (root)
     - กด Save
6. รอ 1–3 นาที รีเฟรชหน้า Pages จะเห็นลิงก์ เช่น
     https://ชื่อผู้ใช้.github.io/vpd-app/


ขั้นที่ 2: ติดตั้งลงมือถือ
-------------------------
เปิดลิงก์ครั้งแรกตอนที่ "มีอินเทอร์เน็ต" (แอพจะเก็บไฟล์ไว้ในเครื่องตอนนี้)

iPhone (ต้องใช้ Safari)
  1. เปิดลิงก์ใน Safari
  2. แตะปุ่มแชร์ (สี่เหลี่ยมมีลูกศรชี้ขึ้น)
  3. แตะ "เพิ่มไปยังหน้าจอโฮม" > เพิ่ม

Android (Chrome)
  1. เปิดลิงก์ใน Chrome
  2. แตะเมนู ⋮ > "ติดตั้งแอป" หรือ "เพิ่มลงในหน้าจอหลัก"

ทดสอบ: เปิดโหมดเครื่องบิน แล้วแตะไอคอน VPD ถ้าแอพเปิดได้ แสดงว่าใช้ออฟไลน์ได้แล้ว


การอัปเดตแอพภายหลัง
--------------------
1. แก้ไฟล์ที่ต้องการ
2. เปิด service-worker.js แล้วเปลี่ยนเลขเวอร์ชันบรรทัดบนสุด
     const CACHE = 'vpd-app-v1';   →   'vpd-app-v2'
   (ถ้าไม่เปลี่ยน มือถือจะยังใช้ไฟล์เก่าที่เก็บไว้)
3. อัปโหลดไฟล์ที่แก้ทับของเดิมใน GitHub > Commit changes
4. บนมือถือ เปิดแอพตอนมีเน็ต 1 ครั้ง ปิดแล้วเปิดใหม่ จะได้เวอร์ชันใหม่


ทางเลือกอื่นแทน GitHub
----------------------
- Netlify (https://app.netlify.com/drop) ลากโฟลเดอร์ไปวางได้เลย
  ต้องสมัครบัญชีฟรีเพื่อให้ลิงก์อยู่ถาวร
- เซิร์ฟเวอร์ภายในบริษัท: ให้ฝ่าย IT วางไฟล์ทั้งชุดบนเว็บเซิร์ฟเวอร์ที่เป็น HTTPS
  (Service worker ทำงานเฉพาะบน HTTPS เท่านั้น)


ข้อควรระวัง
-----------
- ลิงก์ GitHub Pages / Netlify แบบฟรี ใครมีลิงก์ก็เปิดได้
  แอพนี้มีแค่สูตรคำนวณและค่าเป้าหมายทั่วไป ไม่มีข้อมูลการผลิต
  แต่ถ้าบริษัทมีนโยบาย IT ควรแจ้งก่อนใช้งาน หรือใช้เซิร์ฟเวอร์ภายใน
- ถ้าจะใช้เป็นเอกสารอ้างอิงใน SOP ควรควบคุมเวอร์ชันตามระบบเอกสาร GMP
  (เลขเวอร์ชันแสดงอยู่ใต้ชื่อแอพ)
